#+title: 快捷键

按 =C-c C-y= 打开这份文档，=q= 关闭。标题上按 =Tab= 折叠/展开。

* 自己加的
- =C-c C-y= 打开这份文档
- =C-c d= 回到首页
- =C-c e= 打开 Emacs Lisp 手册
- =C-c v= 打开 vterm 终端
- =C-x C-+= / =C-x C--= 放大 / 缩小字体，每级 5%
- =Shift + 方向键= 在窗口之间切换（windmove）

* ido（补全）
=M-x=、=C-x C-f=、=C-x b= 的候选横排在底部，支持模糊匹配（输入 =gtr= 能找到 =gt-translate=）。
- =C-s= / =C-r= 左右切换候选，=RET= 选中
- 输入框为空时 =DEL= 回到上一级目录
- 在 =C-x C-f= 里按 =C-f= 退回普通文件补全（新建和已有文件名字很像的文件时用）
- 在 =C-x C-f= 里按 =C-d= 用 dired 打开当前目录
- =C-x p f= 在当前项目里按文件名找文件

* multiple-cursors（多光标）
选中一个词后按 =C->=，下一个相同的词也会被选中并多出一个光标，继续按就继续加，然后直接打字就是同时修改，=C-g= 退出。
- =C->= / =C-<= 加上下一个 / 上一个相同的内容
- =C-"= / =C-:= 跳过下一个 / 上一个
- =C-c C-<= 一次选中全部
- =C-S-c C-S-c= 选中几行后按，每行放一个光标

* drag-stuff
- =M-↑= / =M-↓= 把当前行或选中的几行上下移动

* company（自动补全）
输入一个字符就弹出。
- =C-n= / =C-p= 上下选
- =Tab= 确认

* lsp-mode + lsp-ui
打开 Rust、Python 文件时自动连接语言服务器；C/C++ 不自动启动，需要时 =M-x lsp=。
- =M-.= 跳到定义，=M-,= 跳回来
- =C-c l= LSP 命令前缀（LSP 启动后才有），停一下 which-key 会列出所有命令
- =C-c l r r= 重命名
- =C-c l a a= 代码操作
- ~C-c l = =~ 格式化

* flycheck（错误和警告）
- =C-c ! n= / =C-c ! p= 跳到下一个 / 上一个错误
- =C-c ! l= 列出全部

* yasnippet（代码片段）
- =Tab= 跳到片段里下一个要填的位置

* magit
- =C-x g= 打开 Git 界面

* gt（翻译）
- =C-c t= 翻译选中的英文，译文显示在侧边窗口；没选中就翻译光标处的词

* dired
- 开两个 dired 窗口时按 =C= 复制、=R= 移动，目标会自动填成另一个窗口的目录

* nov（读 epub）
用 =C-x C-f= 打开 =.epub= 文件就进入阅读模式。
- =SPC= / =DEL= 往下 / 往上翻页，翻到底自动进下一章
- =n= / =p= 下一章 / 上一章
- =t= 目录，在目录里 =RET= 跳过去
- =l= / =r= 在跳转历史里后退 / 前进（点过链接或目录后用）
- =m= 查看书名、作者等信息
- =g= 重新排版（改了窗口大小后用）
- =q= 关闭
